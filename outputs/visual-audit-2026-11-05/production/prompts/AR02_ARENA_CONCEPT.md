# AR02 — The Broken Processional Court: environment concept prompt

Attach R08, R09, R03 from ../references. This optional concept is for layout/mood.

Check for an existing approved scene concept in the project and ForgeGUI library first. If a new concept is useful and within this batch, use a verified ForgeGUI opaque widescreen image route (currently generation_image type thumbnail) or the creator's chosen image tool. Use the following text as the visual brief. A scene image guides composition; create only missing individual 3D props through ForgeGUI and construct precise playable space with Blender/Roblox. See [ASSET_WORKFLOW.md](../ASSET_WORKFLOW.md).

```text
Create an original environment concept for Asura's Path, a monumental grim dark fantasy boss arena titled "The Broken Processional Court". Use the attached reference images for scale, depth and material atmosphere rather than reproducing their exact landmarks, characters or HUD. A fallen fortified ceremonial precinct of an older stone civilization: vast broken limestone domes, tiered processional stairs, deep arcades and a partially collapsed aqueduct on cliffs. The main court is broad, level, worn pale stone with subtle wheel/foot traffic patterns and a few inlaid processional lines. Monumental empty guard plinths and reused worn statues frame the entrance and far stair. The actual fight floor remains open enough for Bull and Zhao together. Weathered ochre-grey masonry, soot and dark leafless trees; restrained ceremonial bronze. The neighboring monastery can retain its East Asian layers while this older foundation uses Romanesque/sepulchral architecture. The narrow ridge pass turns before opening onto the full facade and two defended silhouettes. Large foreground masonry frames a distant dome, with another city tier far behind it. Show a plausible traversable connection to the existing monastery, not a freestanding square grey pad. Show a default third-person player-height view from just inside the entrance, roughly 70-degree field of view. One small neutral player silhouette near the foreground and a simple non-designed mass at the intended boss station communicate scale; do not redesign or illustrate a new boss. Show a large navigable combat core clearly separated from peripheral terrain, believable building/landscape support, a visible entry and an implied return route. Three readable depth layers: tactile foreground frame, open midground fight, distant monumental landmark/skyline. Palette restrained and grounded, powerful silhouette hierarchy, asymmetry from age rather than random ornamental noise, calm walkable surfaces, natural wear at seams and foundations. No tiny diorama, fisheye lens, generic fantasy asset collage, overcrowded floor, excessive bloom, painted-on geometry, text or interface. Wide 16:9 composition. This is a level-design mood/scale image, not a whole-arena 3D generation request.
```

Then ask separately, using the approved image:

```text
Make a legible orthographic top-down layout study of this same approved arena. Preserve its actual circulation and landmark relationships. Include a simple scale bar based on the chosen Roblox design dimensions, not dimensions guessed from the source screenshot. Do not add new obstacles, bosses or a second level. Return an image for visual planning; the agent must still implement and verify coordinates from the authored spatial manifest.
```
