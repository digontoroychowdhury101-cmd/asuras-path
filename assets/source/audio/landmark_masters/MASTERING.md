# Landmark audio masters

These 17 PCM masters derive from the original ElevenLabs files in the parent SFX ledger. Each loop uses a 200 ms equal-power overlap from the original end to the beginning and is 200 ms shorter. The gate slam and temple gong use a 4 ms onset fade. Constant gain reduction supplied headroom whenever an edited file exceeded −1 dBFS. The other nine sounds use their original MP3 files.

The pre-edit waveform report gives the 26 original hashes, RMS and peak levels, and first-to-last sample differences. The review is numerical.
