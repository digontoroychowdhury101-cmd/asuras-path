# Sanctuary micro-landscape kit

Original Blender geometry, five shared single-material meshes (1,382 triangles total). All are decorative; gameplay uses the established collision supports. Rebuild with:

`/Applications/Blender.app/Contents/MacOS/Blender -b --python-exit-code 1 -P tools/blender/sanctuary_detail.py`

Import `AsuraSanctuaryDetail.glb` through Studio 3D Importer, Creator: Me. The persisted Rojo library `assets/models/AsuraSanctuaryDetail.rbxmx` has normalized floor pivots, Automatic RenderFidelity, double-sided foliage, no collision/shadows, reused uploaded Vista rock maps and the existing branch alpha texture. The quad's pivot is its centre. `assets/SANCTUARY_DETAIL_UPLOADED.json` records IDs; do not invent replacements.

Rock source maps: Poly Haven rock_face_03 CC0, already credited. No whole buildings or bridges were generated.
